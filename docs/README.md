# Documentation Hub

This folder is the documentation hub for ReadTheRoom. It separates current project documentation from reference notes and archived design material.

## Start Here

- [Architecture](architecture.md): current app layers, runtime responsibilities, and data flow.
- [Game Flow](game-flow.md): player journey, choice processing, summary flow, and ending flow.
- [Scenario Format](scenario-format.md): current JSON scenario structure used by the runtime.
- [Testing Strategy](testing-strategy.md): validation model, coverage reporting, and future UI testing priorities.
- [Release Checklist](release-checklist.md): automated checks and Expo Go smoke-test checklist.
- [Roadmap](roadmap.md): near-term product, content, and technical priorities.

## Project Policies

- [Contributing](contributing.md): contribution rules, scenario-change expectations, and commit hygiene.
- [Encoding Policy](encoding-policy.md): UTF-8, Korean localization, and mojibake recovery rules.
- [Legacy Backend](legacy-backend.md): where the removed .NET backend lives in Git history.

## Reference Areas

- `characters/`: character notes and story source material.
- `design/`: UX and visual design source notes.
- `schema/`: historical JSON schema notes and scenario-format references.
- `system-design/`: refactoring notes and archived system design material.
- `story-drafts/`: archived story draft material.

## Portfolio Status

Current English `.md` files are the official portfolio-facing documentation.

Korean `.ko.md` source notes are retained as reference material. They are useful for product thinking and future summaries, but they are not official portfolio-facing documentation until an English summary is written.
