# Amazon Appstore Submission Checklist

## Account and App Record

- [ ] Amazon Developer Console account profile is complete.
- [ ] New app record is created as an Android / Fire OS tablet app.
- [ ] Package name is confirmed as `com.spdshts.readtheroom`.
- [ ] Customer support email is set to `joygle.dev@gmail.com`.
- [ ] Fire TV is not selected as a supported target for this release.

## Binary and Device Validation

- [ ] Upload the production `.aab`; do not commit it to Git.
- [ ] Confirm the app installs and launches on a Fire tablet.
- [ ] Confirm portrait layout, safe areas, and navigation work on Fire OS.
- [ ] Confirm Ken and Amy can begin and progress through their supported content.
- [ ] Confirm Korean and English switching works.
- [ ] Confirm local progress restoration works after restart.
- [ ] Confirm the optional rewarded-ad recovery path either loads correctly or fails safely without blocking progress.
- [ ] Confirm no Play Store-only dependency blocks gameplay on Fire OS.

## Listing Content

- [ ] Choose a product category appropriate for a story / choice game.
- [ ] Add a plain-text short description.
- [ ] Add a plain-text long description (maximum 4,000 characters).
- [ ] Add three to five product feature bullets.
- [ ] Add English as a supported language.
- [ ] Add Korean if the Korean localized listing is published.
- [ ] Provide customer support contact details.
- [ ] Provide a public privacy policy URL.

## Image Assets

- [ ] Upload one 114 x 114 transparent PNG icon.
- [ ] Upload one 512 x 512 transparent PNG icon.
- [ ] Upload at least three Fire tablet screenshots.
- [ ] Verify screenshots contain no debug error, developer menu, test overlay, or personal information.
- [ ] Optional: upload one 1024 x 500 promotional image.

## Policy and Submission

- [ ] Review the app content against Amazon Appstore Content Policy.
- [ ] Declare that this release has no Amazon in-app purchases.
- [ ] Confirm the privacy policy accurately discloses optional Google Mobile Ads / AdMob rewarded advertising.
- [ ] Confirm the app does not require Login with Amazon or a security profile.
- [ ] Submit for review after all required fields show complete in Developer Console.
