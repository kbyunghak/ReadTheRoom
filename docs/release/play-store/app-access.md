# App Access Notes

## Login Required?

No. The current release does not require a user account or password to reach gameplay.

## Reviewer Instructions

- Start the app.
- Continue from the splash and warning screens.
- Choose a character and play through the story.
- Check the StoryMap, feedback modal, and failure recovery flow.
