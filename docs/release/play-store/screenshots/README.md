# Screenshot Checklist

Create and upload at least:

- 2 English screenshots
- 2 Korean screenshots

Recommended filenames:

- `en-US/phone-01.png`
- `en-US/phone-02.png`
- `ko-KR/phone-01.png`
- `ko-KR/phone-02.png`

Useful capture moments:

- Splash or title screen
- Character select screen
- Game scene with choices
- StoryMap or feedback modal
