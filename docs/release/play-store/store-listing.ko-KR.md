# Google Play Store Listing - ko-KR

## 앱 이름

Read The Room

## 짧은 설명

사회적 상황을 읽고 다음에 무엇을 말할지 선택하는 한/영 스토리 게임입니다.

## 전체 설명

Read The Room은 밴쿠버를 배경으로 한 한/영 선택형 스토리 게임입니다.

상황을 읽고, 적절한 표현을 고르고, 선택의 결과를 바로 확인해보세요. 각 선택은 이야기의 흐름과 스탯, 그리고 이후에 받는 피드백에 영향을 줍니다.

주요 기능:

- 한국어 / 영어 이중 언어 지원
- 선택에 따라 진행되는 스토리
- 캐릭터별 진행 루트
- 완료한 장면으로 돌아갈 수 있는 StoryMap
- 선택 이후 피드백과 스탯 변화 확인
- 여러 분기와 엔딩을 다시 즐길 수 있는 구조

현재 버전은 핵심 스토리 경험 중심으로 구성되어 있으며, 이후 콘텐츠와 밸런스 업데이트가 이어질 수 있습니다.
