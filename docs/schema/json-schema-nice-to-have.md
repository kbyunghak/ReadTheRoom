# Scenario System Nice-To-Have Ideas

> Status: Portfolio summary
> Source note: [json-schema-nice-to-have.ko.md](json-schema-nice-to-have.ko.md)

This document summarizes future scenario-system ideas that are intentionally outside the current release scope.

## Purpose

These ideas are useful for long-term product direction, but they should not block release stabilization.

They should be considered after the core story flow, save/resume behavior, localization, and release checks remain stable.

## Future Ideas

### AI-Based Personal Diary

Use the player's selected feedback history to generate a first-person daily diary from the character's perspective.

Potential value:

- Makes each playthrough feel more personal.
- Turns choices into a memorable reflection.
- Reinforces the emotional result of the day.

Risk:

- Requires careful privacy and content-safety decisions.
- Needs strong fallback behavior if AI generation is unavailable.

### Play Style Report

Analyze the player's choice tendencies, such as Growth or Realist selections, and return a personality-style title.

Potential value:

- Encourages replay.
- Helps players understand their decision pattern.
- Can become a lightweight post-day reward.

### Visual Timeline

Show day-by-day progress with thumbnails based on important background images.

Potential value:

- Makes the settlement journey easier to understand.
- Gives players a visible memory path.
- Supports portfolio-friendly visual storytelling.

### English Review Collection

Collect useful expressions from Growth choices and let players review them later.

Potential value:

- Connects the visual novel structure to language learning.
- Gives practical value beyond the story.
- Supports future quiz or spaced-review modes.

## Summary System Ideas

The source note also explores how day summaries could be generated or composed:

- Tips can provide stable universal guidance.
- Feedback can reflect the player's actual choices.
- Situation titles can form a lightweight timeline.

The safest near-term approach is to use curated tips and selected feedback rather than fully generated summaries.

## Portfolio Notes

These ideas show how ReadTheRoom can grow beyond a linear choice game into a reflective learning experience. They should remain future-facing until the core game loop and release workflow are fully stable.
